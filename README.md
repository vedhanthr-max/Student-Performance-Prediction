# 🎓 Student Performance Prediction using Supervised Machine Learning

## 📌 Project Overview

This project predicts student performance using multiple supervised machine learning algorithms and compares their accuracy to identify the best-performing model.

A Flask web application is used to provide a simple user interface where users can enter student details and receive predictions.

---

## 🚀 Features

- Student Performance Prediction
- Comparison of Multiple Machine Learning Algorithms
- Accuracy Comparison Graph
- Flask Web Application
- User-Friendly Interface

---

## 🛠 Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- Joblib

---

## 🤖 Machine Learning Algorithms

- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Naive Bayes
- XGBoost

---

## 📊 Input Parameters

- Study Hours
- Attendance
- Assignment Marks
- Internal Marks

---

## 📈 Output

The model predicts one of the following:

- Fail
- Pass
- Excellent

---

## ▶️ How to Run

### Install Libraries

```bash
pip install -r requirements.txt
```

### Train the Model

```bash
python main.py
```

### Run the Flask Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
